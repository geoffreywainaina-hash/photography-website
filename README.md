# PHOTOGRAPH WEBSITE

A responsive photography portfolio website built with HTML and CSS, featuring an interactive gallery, elegant navigation, and a mdern design for showcasing photographic work.

## FEATURES

- Responsive design
- Navigation buttons
- Hero image section
- Image hover 
- navigation buttons 

## TECHNOLLOGIES USED
- HTML
- CSS
